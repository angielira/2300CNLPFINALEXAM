# HelpMate labeling guide

Categories: Printer, Email, Wi-Fi/Internet, Passwords/Login, Computer slow, Phone/Apps, Files/Storage, Video calls.

- Label the problem the user needs fixed first.
- Frustrated = strong negative emotion (caps, repeated `!`, "nothing works", "again", "useless").
- Write seed questions the way a non-technical person would: vague, misspelled, emotional, short.
- Columns: `id, text, category, frustrated, source`.
