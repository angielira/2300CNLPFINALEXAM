# Dataset options

1. **Customer Support Tickets** (Hugging Face, Tobi-Bueck): ~61.8k tickets, English and German; fields subject, body, answer, type, queue, priority, language, tags; queues include IT Support and Technical Support. License CC BY-NC 4.0; creator Softoft; DOI 10.57967/hf/6184. Origin (real vs synthetic) not clearly stated.
2. **Super User** (Stack Exchange data dump): real user questions; CC BY-SA (version by date); large download; attribution per post required.
3. **HelpMate seed set**: our own plain-language questions (no license issue).
