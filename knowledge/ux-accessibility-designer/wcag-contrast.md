# WCAG 2.2 contrast

- SC 1.4.3 (AA): text >= 4.5:1; large text (18pt, or 14pt bold, about 24px / 18.5px) >= 3:1. Thresholds are strict (4.499 fails).
- Exceptions: incidental text, logotypes.
- SC 1.4.11 (AA): non-text content (icons, chart marks, control borders) >= 3:1.
