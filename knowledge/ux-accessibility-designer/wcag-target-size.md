# WCAG 2.2 target size

- SC 2.5.8 Target Size (Minimum), AA: pointer targets at least 24x24 CSS px, with exceptions (spacing, equivalent, inline, user-agent, essential).
- SC 2.5.5 Target Size (Enhanced): 44x44 CSS px; recommended for important controls.
- Zoom doesn't count toward meeting the requirement.

## HelpMate
All buttons 44x44 or larger.
