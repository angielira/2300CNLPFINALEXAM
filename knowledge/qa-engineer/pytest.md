# pytest

- Install in a virtual environment: `pip install -U pytest`.
- Discovery: `test_*.py` / `*_test.py`, functions `test_*`, classes `Test*`.
- `assert` shows intermediate values; `pytest.raises`; `tmp_path`; `pytest.approx` for floats.
- `pytest -q` for short output.
