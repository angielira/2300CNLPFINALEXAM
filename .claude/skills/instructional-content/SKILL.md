# instructional-content

Used by: instructional-designer, ux-accessibility-designer

## Answer shape (per category)
- `see_it`: 4-8 numbered steps, each with a short label and what the user will see.
- `hear_it`: a friendly script, one step per sentence, to be read aloud.
- `try_it`: the same steps as checkboxes the user ticks as they go.
- `read_it`: a printable checklist.

## Mini-course (10 steps)
Each step: one idea · one everyday example · one quick check question (retrieval practice).

## Voice
Warm, short sentences, no jargon, explain a term once, never blame the user.
