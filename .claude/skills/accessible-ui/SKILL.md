# accessible-ui

Used by: ux-accessibility-designer, frontend-engineer, data-viz-expert, qa-engineer

## Checklist
- Text contrast >= 4.5:1 (large text >= 3:1); icons and chart marks >= 3:1.
- Targets >= 24x24 CSS px (AA); HelpMate aims for 44x44 on all buttons.
- Visible focus outline; full keyboard use; real `<button>`, `<label>`.
- Don't use color alone; icons and text labels on every format button.
- Plain language; reading level about grade 6-8.
- Works at 360 px wide.
