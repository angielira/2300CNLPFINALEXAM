# dataset-licensing

Used by: dataset-curator, nlp-evaluator

## Checklist
- Record source URL, license, creator, date accessed and any DOI in `data/README.md`.
- CC BY-NC: non-commercial use with attribution (OK for coursework).
- CC BY-SA (Stack Exchange): attribute and link each question/author; derivatives share alike.
- Data we write ourselves (seed set): state it is original.
- Never commit personal data; remove names and emails from samples.
